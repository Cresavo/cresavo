# B1 · Apron tie

A loose end of an apron string folds back, crosses itself and trails off to the right. It pairs with Pen note. The lettering leans forward while the loop leans back, leaving a clear break before the name.

The loop is the favicon, app icon and avatar. Its opening stays visible at 16 px. A first-time viewer may see a pen flourish before recognising a tie. This is the strongest standalone symbol of the four for me.
