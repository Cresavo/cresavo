# Open-source launch

The public repository contains the concept demo, booking engine and the
guides needed to run them or contribute. The hosted demo uses fictional
data. [Project status](STATUS.md).

- The [launch checklist](LAUNCH_CHECKLIST.md) covers repository settings,
  community setup and publishing releases. The [launch plan](LAUNCH_PLAN.md)
  covers outreach, feedback and post drafts.
- [Contributing](../CONTRIBUTING.md) explains the contribution and review
  process. The contributor agreement and trademark policy are drafts pending
  legal review. [Draft CLA](legal/CLA.md) · [Draft trademark policy](../TRADEMARK.md).
- [Third-party notices](../THIRD_PARTY_NOTICES.md) document dependencies and
  demo assets. [Security](../SECURITY.md) explains private vulnerability
  reporting.
- [Brand and naming](BRAND.md) explains how Cresavo is presented and which
  technical identifiers retain their earlier names.
