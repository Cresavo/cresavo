# Roadmap

The [goal queue](goals/QUEUE.md) is the source of truth for priorities, status
and completion criteria. Cresavo starts with salons and aims to give business
owners the same core booking capabilities through the workspace, APIs and
approved agent actions.

- **QA fixes** — Close current findings and verify the key studio, booking and
  product-site journeys on mobile and desktop.
- **International by default** — Use English as the source language. Add
  business-level locale, currency and time zone, with country-specific services
  behind adapters.
- **Connections** — Build the connections owners need for email, phone and
  campaign publishing. Define permissions, setup and approval flows.
- **Own domain** — Turn demo setup into a verified connection with clear
  DNS, certificate and ownership status.
- **Calm settings** — Make common preferences easy to find and keep advanced
  options with the features they control.
- **Salon site** — Develop the business-branded site around services, staff,
  reviews and a direct path to booking.
- **Pilot readiness** — Connect the studio to the booking engine, prove tenant
  isolation, and complete the security, privacy and operations pilot gate.
- **Open-source launch** — Prepare clean public repositories, contributor and
  trademark terms, and security checks before owner-approved publication.
