# Arkiv

Tidigare planer, leveransrapporter, QA-rapporter, skärmdumpar och bevis från
prototypens första fas (oktober–november 2026). Filerna flyttades hit oförändrade
den 2026-11-16.

Arkivet är historik. Det ger inga uppdrag, och det som står här är inget bevis för
hur koden fungerar idag. Aktuellt läge finns i [STATUS](../STATUS.md) och
riktningen i [ROADMAP](../ROADMAP.md).

- [README_HISTORY](README_HISTORY.md) – den tidigare README:n med alla leveransavsnitt
- [AGENTS_HISTORY](AGENTS_HISTORY.md) – tidigare uppdragsinstruktioner
- [PRODUCT_ROADMAP](PRODUCT_ROADMAP.md) – den fullständiga produktvisionen
- [VERIFICATION](VERIFICATION.md) och [qa/](qa/) – testresultat och granskningar
- [LEGACY_DECOUPLE_PLAN](LEGACY_DECOUPLE_PLAN.md) – detaljerade grindar för att koppla loss äldre kod
- [OAUTH_LAB](OAUTH_LAB.md) – hur OAuth-labbet fungerar, underlag för fjärr-MCP
- [research/](research/) – omvärldsanalys från 2026-11-13
