# Archive

Earlier plans, delivery reports, QA reports, screenshots and evidence from the
prototype's first phase (October to November 2026), when the project was
called Booking Lab. The files were moved here unchanged on 2026-11-16 and are
mostly in Swedish.

The archive is history. It gives no assignments, and nothing here proves how
the code works today. The current state is in [STATUS](../STATUS.md) and the
direction in [ROADMAP](../ROADMAP.md).

Before the public release (2026-11-18) the raw evidence was removed:
`verification/`, `qa/evidence-*/` and the proof JSON and text files under
`assets/` (CI logs, deployment metadata, perimeter probes). Links to those
paths in the archived documents are dead by design. Private preview URLs,
deployment IDs and local machine paths in the remaining files are redacted
as `<redacted-…>` or `<user>`.

- [AGENTS_HISTORY](AGENTS_HISTORY.md): earlier agent instructions

- [LEGACY_DECOUPLE_PLAN](LEGACY_DECOUPLE_PLAN.md): detailed gates for decoupling older code
- [OAUTH_LAB](OAUTH_LAB.md): how the OAuth lab works, groundwork for remote MCP
