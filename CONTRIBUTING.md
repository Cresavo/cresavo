# Bidra

Använd syntetiska uppgifter. Skapa en liten ändring med tester, kör `npm run lint`, `npm test` och `npm run build`, samt relevanta integrationstester enligt README. Kopiera inte kod eller tillgångar utan dokumenterad licens- och ursprungskontroll. Bidrag lämnas under projektets AGPL-3.0-only; behåll tredjepartsnotiser och beskriv ändringar.
